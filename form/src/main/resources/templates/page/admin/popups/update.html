이미지 URL을 입력해주세요.
팝업에 표시할 이미지의 URL을 입력하세요.

JPG, PNG, GIF 형식의 이미지 파일을 업로드하세요.

수정 안내
  • 팝업 타입에 따라 표시 방식이 결정됩니다.
  • 이미지 관리:
    • 변경 안 함: 기존 이미지 유지
    • URL 입력: 새 이미지 URL로 교체
    • 파일 업로드: 새 이미지 파일로 교체
    • 현재 이미지 삭제 버튼: 이미지 제거
  • 링크 URL은 선택사항이며, 입력 시 팝업 클릭 시 해당 URL로 이동합니다.
  • 시작일시와 종료일시를 설정하여 표시 기간을 제한할 수 있습니다.
  • 표시 여부를 체크해제하면 팝업이 노출되지 않습니다.
  • 팝업 번호는 수정할 수 없습니다.
